# twilio-whatsapp-llm-demo

In this repo we spin up a Flask app that can links messages received through WhatsApp via 
Twilio to a given LLM, in this case, Claude.

## Prior requirements

- Get a Twilio API key
- Get an LLM provider (either cloud or local)
